# xlsx-editor.html

ブラウザだけで動く、Excel 形式（.xlsx / .xls）のスプレッドシートエディタです。
**HTML ファイル 1 つ**で完結し、インストール・サーバー・インターネット接続は不要です。ファイルの中身が外部に送信されることもありません。

- 値・数式の編集と、ブラウザ上での再計算
- グラフの作成（9 種類）、画像の挿入
- 既存の xlsx に含まれる画像・グラフを保持したまま保存

PowerPoint（.pptx / .ppt）を編集できる `pptx-editor.html`、Word（.docx / .doc）を編集できる `docx-editor.html`、動画を編集できる `video-editor.html` も同梱しています。使い方は [pptx-editor.html（PowerPoint 版）](#pptx-editorhtmlpowerpoint-版)・[docx-editor.html（Word 版）](#docx-editorhtmlword-版)・[video-editor.html（動画版）](#video-editorhtml動画版) を参照してください。

## 使い方

1. `xlsx-editor.html` をダウンロードし、ダブルクリックしてブラウザで開きます。
2. 「開く」ボタン、またはファイルのドラッグ＆ドロップで .xlsx / .xlsm / .xls / .csv を読み込みます（「新規」で空のブックからも始められます）。
3. 編集して、`Ctrl+S` で保存します。

### 対応ブラウザ

| ブラウザ | 動作 | 保存 |
|---|---|---|
| Chrome / Edge（推奨） | ○ | 元のファイルへの上書き保存、保存先の選択に対応 |
| Firefox / Safari | ○ | 保存のたびにダウンロード |
| Android（Chrome） | ○ | 保存のたびにダウンロード（「ダウンロード」フォルダに保存） |
| iPhone / iPad（Safari） | ○ | 保存のたびにダウンロード（「ファイル」アプリの「ダウンロード」に保存） |

### スマートフォン・タブレットで使う

スマートフォンでは、ダウンロードした HTML ファイルをそのまま開けないことがあります（iPhone の「ファイル」アプリはプレビュー表示になり、Android の Chrome は端末内の HTML を開けない場合があります）。
**GitHub Pages などで公開した URL をブラウザで開く**のが確実です。GitHub Pages の場合、リポジトリの Settings → Pages で公開すると `https://<ユーザー名>.github.io/<リポジトリ名>/xlsx-editor.html` で開けます。

ページを開いたあとは、ファイルの読み込み・編集・保存はすべて端末の中で行われ、ファイルの中身が送信されることはありません。

| 操作 | 方法 |
|---|---|
| ファイルを開く | 「開く」→ 端末内や「ファイル」アプリ、Google ドライブなどから選ぶ |
| セルを選ぶ | タップ |
| セルを編集 | 選んだセルをもう一度タップ（または数式バーをタップ）。確定は改行キー |
| 範囲を選ぶ | 「範囲選択」ボタンを押してから、範囲の端のセルをタップ（行・列の番号のタップで行・列全体） |
| コピー・貼り付け・行列の挿入削除など | セルを長押ししてメニューから選ぶ |
| シート名の変更 | シートのタブを長押し |
| 画像・グラフの移動 | タップで選んでからドラッグ。右下の ○ でサイズ変更 |
| グラフの編集・画像やグラフの削除 | 長押ししてメニューから選ぶ |
| 保存 | 「保存」または「xlsx で保存」でダウンロード |

## 機能

### セルと数式

- セルに直接入力（日本語入力に対応）、ダブルクリックや `F2` で修正、数式バーでも編集できます
- 数式は編集のたびに、影響するセルだけをブラウザ上で再計算します（ほかのシートへの参照にも対応）
- ファイルを開いた直後は、Excel が保存した計算結果をそのまま表示します。「再計算」（`F9`）ですべて計算し直します
- 範囲選択（ドラッグ、Shift+クリック、Shift+矢印、行・列の見出しのクリック）
- 範囲のコピー・貼り付け（数式は相対参照をずらして貼り付け。Excel からの複数セルの貼り付けにも対応）
- 下方向・右方向へのコピー（`Ctrl+D` / `Ctrl+R`）、オート SUM（`Alt+=`）
- 右クリックで行・列の挿入と削除（数式やグラフの参照も合わせて調整）
- 範囲を選ぶと、ステータスバーに合計・平均・データの個数を表示
- シートの切り替えと追加
- シート名の変更（タブをダブルクリック、または右クリック →「シート名の変更」）。ほかのセルの数式やグラフがそのシートを参照していれば、参照先のシート名も合わせて書き換えます

### 対応している関数

| 分類 | 関数 |
|---|---|
| 数学・集計 | SUM, PRODUCT, AVERAGE, MIN, MAX, COUNT, COUNTA, COUNTBLANK, SUMPRODUCT, ROUND, ROUNDUP, ROUNDDOWN, TRUNC, INT, ABS, MOD, POWER, SQRT, EXP, LN, LOG, LOG10, PI, SIGN, CEILING, FLOOR, RAND |
| 統計 | MEDIAN, STDEV(.S/.P), VAR(.S/.P), LARGE, SMALL, RANK(.EQ) |
| 条件付き集計 | SUMIF(S), COUNTIF(S), AVERAGEIF(S), MAXIFS, MINIFS |
| 論理 | IF, IFS, IFERROR, IFNA, AND, OR, NOT, SWITCH, CHOOSE, ISBLANK, ISNUMBER, ISTEXT, ISERROR, ISNA |
| 検索 | VLOOKUP, HLOOKUP, XLOOKUP, INDEX, MATCH, ROW, COLUMN, ROWS, COLUMNS |
| 文字列 | LEN, LEFT, RIGHT, MID, UPPER, LOWER, PROPER, TRIM, CONCAT, CONCATENATE, TEXTJOIN, SUBSTITUTE, FIND, SEARCH, REPT, VALUE, TEXT, EXACT |
| 日付・時刻 | TODAY, NOW, DATE, YEAR, MONTH, DAY, WEEKDAY, TIME, HOUR, MINUTE, SECOND, EDATE, EOMONTH, DATEDIF |

未対応の関数を含むセルは、ファイルに保存されていた値をそのまま表示します（点線の下線で表示し、ステータスバーでもお知らせします）。

### グラフ

- データ範囲を選んで「グラフ」ボタン（1 セルだけ選んでいる場合は、周りのデータの塊を自動で範囲にします）
- 縦棒・積み上げ縦棒・横棒・折れ線・面・円・ドーナツ・散布図・レーダー
- セルの値を変えるとすぐに更新されます。ダブルクリックで種類・タイトル・範囲を編集できます
- xlsx に保存すると、Excel のネイティブなグラフ（セル範囲を参照するグラフ）として書き出されます

### 画像

- 「画像」ボタン、ドラッグ＆ドロップ、`Ctrl+V` で挿入できます（PNG / JPEG / GIF / BMP。WebP などは自動で PNG に変換）
- 画像・グラフはドラッグで移動、選択すると右下に出る □ でサイズ変更、`Delete` で削除できます
- 既存の xlsx に含まれる画像・グラフも表示され、保存時は元の書式のまま残ります

### 保存

| 操作 | 内容 |
|---|---|
| `Ctrl+S` / 「保存」 | 開いたファイルに上書き。新規の場合は保存先を選んだあと、以降は上書き |
| `Ctrl+Shift+S` / 「xlsx で保存」 | 名前を付けて保存 |
| 「xls で保存」 | Excel 97-2003 形式で保存（下の制限を参照） |

## 制限事項

- **xls 形式で保存すると、数式・画像・グラフは保存されません**（数式は計算結果の値だけが残ります）。保存前に確認メッセージが表示されます。
- **セルの書式（色・罫線・フォントなど）は、保存すると失われます。**
- Excel で作成されたグラフは、移動・サイズ変更・削除のみできます（内容の編集はできません）。ブラウザ上の表示は近い見た目で、Excel と完全には同じになりません。また、行・列を挿入・削除しても、これらのグラフの参照範囲は調整されません。
- セルの結合の表示、図形・SmartArt の表示、条件付き書式、ピボットテーブル、マクロの実行には対応していません（図形などは保存時にそのまま残ります）。
- 配列数式・名前付き範囲・INDIRECT / OFFSET などは計算できません（ファイルに保存されていた値を表示します）。

- スマートフォンでは、開いたファイルへの上書き保存はできません（保存のたびに新しいファイルとしてダウンロードされます）。

大切なファイルは、編集前にコピーを取ってからお使いください。

## pptx-editor.html（PowerPoint 版）

ブラウザだけで動く、PowerPoint 形式（.pptx / .ppt）のプレゼンテーションエディタです。
`xlsx-editor.html` と同じく **HTML ファイル 1 つ**で完結し、インストール・サーバー・インターネット接続は不要です。外部ライブラリも使っていません（ZIP の展開・圧縮はブラウザ標準の機能で行います）。

### 使い方

1. `pptx-editor.html` をダウンロードし、ダブルクリックしてブラウザで開きます。
2. 「開く」ボタン、またはファイルのドラッグ＆ドロップで .pptx / .pptm / .potx / .ppsx / .ppt / .pps / .pot を読み込みます（「新規作成」で空のプレゼンテーションからも始められます）。
3. 編集して、`Ctrl+S` で保存します。保存形式は常に .pptx です。

| 操作 | 方法 |
|---|---|
| スライドの追加 | 「新しいスライド」（`Ctrl+M`）。横のメニューでレイアウトを選べます |
| スライドの複製・削除・並べ替え | ツールバーのボタン、または左のサムネイルをドラッグ |
| 図形・テキストの選択 | クリック |
| 移動・サイズ変更・回転 | ドラッグ、四隅と辺のハンドル、上の ○ ハンドル。矢印キーでも少しずつ移動できます |
| 文字の編集 | ダブルクリック（または選択して `Enter` / `F2`）。`Esc` か `Ctrl+Enter` で確定 |
| 書式の変更 | 右のプロパティパネルで、塗りつぶし・枠線・フォント・サイズ・太字・色・揃え・箇条書きなどを変更 |
| 挿入 | テキストボックス、図形（16 種）、画像（ボタン・ドラッグ＆ドロップ・`Ctrl+V`）、表 |
| 表の編集 | ダブルクリックでセルを編集。行・列の追加と削除はプロパティパネルから |
| ノート | スライドの下のノート欄に入力 |
| スライドショー | `F5`。矢印キー・クリックで進む／戻る、`Esc` で終了 |
| 印刷・PDF | 「印刷」ボタンから、ブラウザの印刷機能で印刷または PDF に保存 |

### 保存

| 操作 | 内容 |
|---|---|
| `Ctrl+S` / 「保存」 | 開いた .pptx に上書き（Chrome / Edge）。それ以外のブラウザや .ppt から開いた場合は、保存先の選択またはダウンロード |
| `Ctrl+Shift+S` / 「名前を付けて保存」 | 名前を付けて .pptx で保存 |

編集していない部分（アニメーション・グラフ・SmartArt など）は、元のファイルの内容をそのまま残して保存します。

### キーボードショートカット

| キー | 動作 |
|---|---|
| Ctrl + O / Ctrl + S / Ctrl + Shift + S | 開く / 保存 / 名前を付けて保存 |
| Ctrl + Z / Ctrl + Y（Ctrl + Shift + Z） | 元に戻す / やり直し |
| Ctrl + M | 新しいスライド |
| Ctrl + D | 選択中の図形を複製（未選択ならスライドを複製） |
| Ctrl + C / X / V | 図形のコピー / 切り取り / 貼り付け（画像・テキストの貼り付けにも対応） |
| Delete / Backspace | 選択中の図形を削除 |
| 矢印（Shift で大きく、Ctrl で細かく） | 選択中の図形を移動。未選択ならスライドの切り替え |
| Enter / F2 | 選択中の図形の文字や表を編集 |
| Esc | 選択の解除 |
| F5 | スライドショー |

### 対応ブラウザ

最新の Chrome / Edge / Firefox / Safari で動作します。上書き保存は Chrome / Edge のみ対応で、そのほかのブラウザでは保存のたびにダウンロードになります。

### 制限事項

- **.ppt 形式では保存できません。** .ppt を開くと .pptx に変換して読み込み、保存は .pptx になります。変換では、文字（サイズ・太字・色・フォント）・図形・画像・表・背景を再現しますが、マスターの細かい書式やアニメーションは引き継がれません。
- グラフ・SmartArt・EMF / WMF / TIFF 画像は枠だけを表示し、編集できません（.pptx では保存時にそのまま残ります）。
- 文字の書式は、図形の中の文字全体にまとめて適用されます（一部の文字だけを変えることはできません）。
- アニメーション・画面切り替え効果・動画・音声は再生されません。
- 表示は PowerPoint と完全には同じになりません。保存したファイルの動作は LibreOffice Impress で確認していますが、Microsoft PowerPoint では未確認です。

大切なファイルは、編集前にコピーを取ってからお使いください。

## docx-editor.html（Word 版）

ブラウザだけで動く、Word 形式（.docx / .doc）の文書エディタです。
ほかのエディタと同じく **HTML ファイル 1 つ**で完結し、インストール・サーバー・インターネット接続は不要です。外部ライブラリも使っていません（ZIP の展開・圧縮はブラウザ標準の機能で行います）。

### 使い方

1. `docx-editor.html` をダウンロードし、ダブルクリックしてブラウザで開きます（開くと白紙の文書が用意されているので、そのまま入力できます）。
2. 「開く」ボタン、またはファイルのドラッグ＆ドロップで文書を読み込みます。
3. 編集して、`Ctrl+S` で保存します。

| 読み込める形式 | 内容 |
|---|---|
| .docx / .docm / .dotx / .dotm | Word 2007 以降の形式。段落・見出し・文字書式・箇条書き・表・画像・リンクを編集できます |
| .doc / .dot | Word 97-2003 のバイナリ形式。文字（太字・斜体・下線・色・サイズ・フォント）・段落（揃え・インデント・間隔）・見出し・箇条書き・表・画像を読み込みます |
| .doc（RTF / HTML / MHT 形式のもの）・.rtf | 中身が RTF や Web 形式の .doc も自動で判別して読み込みます |
| .htm / .html / .mht / .txt | Web ページやテキストも読み込めます |

### 編集

| 操作 | 方法 |
|---|---|
| 段落スタイル | 「標準」「見出し 1〜6」と、文書に含まれる段落スタイルから選択 |
| 文字の書式 | フォント・サイズ・太字・斜体・下線・取り消し線・上付き・下付き・文字の色・蛍光ペン・書式クリア |
| 段落の書式 | 左・中央・右・両端揃え、箇条書き、段落番号、インデント（箇条書きの中では `Tab` / `Shift+Tab` でレベル変更） |
| 表 | 「表」で行数・列数を指定して挿入。表の中で右クリックすると、行・列の挿入と削除、罫線の表示切り替え、セルの背景色。`Tab` で次のセルへ（最後のセルでは行を追加） |
| 画像 | 「画像」ボタン、ドラッグ＆ドロップ、`Ctrl+V` で挿入。クリックで選択し、右下の □ をドラッグでサイズ変更、`Delete` で削除 |
| その他 | リンク、改ページ（`Ctrl+Enter`）、検索と置換、表示倍率、印刷（PDF への保存も可） |

Word や Web ページからの貼り付けにも対応しています（不要なスクリプトや書式は取り除いて貼り付けます）。

### 保存

| 操作 | 内容 |
|---|---|
| `Ctrl+S` / 「保存」 | 開いた .docx に上書き（Chrome / Edge）。それ以外のブラウザや .docx 以外から開いた場合は、保存先の選択またはダウンロード（.docx 形式） |
| `Ctrl+Shift+S` / 「名前を付けて保存」 | 名前を付けて .docx で保存 |
| 「doc で保存」 | Word 97-2003 互換の .doc で保存（中身は RTF 形式。Word・LibreOffice でそのまま開けます） |

.docx を保存するときは、本文以外（ヘッダー・フッター・用紙設定・スタイル・テーマなど）は元のファイルの内容をそのまま残します。

### キーボードショートカット

| キー | 動作 |
|---|---|
| Ctrl + O / Ctrl + S / Ctrl + Shift + S | 開く / 保存 / 名前を付けて保存 |
| Ctrl + Z / Ctrl + Y（Ctrl + Shift + Z） | 元に戻す / やり直し |
| Ctrl + B / Ctrl + I / Ctrl + U | 太字 / 斜体 / 下線 |
| Ctrl + Enter | 改ページ |
| Ctrl + F / Ctrl + H | 検索 / 置換 |
| Tab / Shift + Tab | タブ文字の入力（箇条書きではレベル変更、表では次 / 前のセルへ） |
| Ctrl + P | 印刷 |

### 対応ブラウザ

最新の Chrome / Edge / Firefox / Safari で動作します。上書き保存は Chrome / Edge のみ対応で、そのほかのブラウザでは保存のたびにダウンロードになります。

### 制限事項

- **「doc で保存」は Word 97-2003 のバイナリ形式ではなく、RTF 形式で書き出します**（拡張子は .doc で、Word・LibreOffice では普通の .doc と同じように開けます）。箇条書きは記号・番号を文字として書き出します。
- 画面はページ単位ではなく連続した 1 枚の紙として表示します。ヘッダー・フッター・脚注・コメント・変更履歴は表示・編集できません（.docx では保存時にそのまま残ります。本文中の脚注番号は「※」で表示され、保存すると文字になります）。
- 段組み、テキストボックスや図形の位置（本文の下に枠として表示）、画像の文字列の折り返し（行内に表示）、複数のセクションの用紙設定は再現されません。
- 「1.1」のような複数レベルの番号は、各レベルの番号だけを表示します。EMF / WMF / TIFF 画像は枠だけを表示します（保存時は元の画像のまま残ります）。
- .doc（Word 97-2003）の読み込みでは、フローティングの図形・テキストボックス・ヘッダー・フッターは読み込まれません。パスワード付きのファイルと Word 95 以前の形式は開けません。
- 表示は Word と完全には同じになりません。保存したファイルの動作は LibreOffice Writer で確認していますが、Microsoft Word では未確認です。

大切なファイルは、編集前にコピーを取ってからお使いください。

## video-editor.html（動画版）

ブラウザだけで動く動画エディタです。
ほかのエディタと同じく **HTML ファイル 1 つ**で完結し、インストール・サーバー・インターネット接続は不要です。外部ライブラリも使っていません（映像の描画・音声のミックス・書き出しは、すべてブラウザ標準の機能で行います）。素材のファイルが外部に送信されることもありません。

### 使い方

1. `video-editor.html` をダウンロードし、ダブルクリックしてブラウザで開きます。
2. 「開く」ボタン、またはファイルのドラッグ＆ドロップで動画・音声・画像を読み込みます（読み込んだ素材は自動でタイムラインに並びます）。
3. 編集して、「書き出し」（`Ctrl+E`）で動画ファイルに保存します。

| 読み込める素材 | 内容 |
|---|---|
| 動画 | .mp4 / .webm / .mov / .m4v / .mkv など、ブラウザが再生できる形式 |
| 音声 | .mp3 / .wav / .m4a / .aac / .ogg / .flac / .opus など。BGM として音声トラックに置けます |
| 画像 | .png / .jpg / .gif / .webp / .bmp / .svg など。表示時間を指定して映像トラックに置けます |

最初に読み込んだ動画（または画像）に合わせて、出力サイズが自動で決まります（長辺は最大 1920 ピクセル）。ツールバーの「サイズ」で、フル HD・縦動画・正方形などに変更できます。

### 編集

| 操作 | 方法 |
|---|---|
| トリミング | タイムラインのクリップの端をドラッグ |
| 並べ替え・移動 | クリップの中央をドラッグ（映像は並べ替え、テキスト・音声は位置を移動）。素材の一覧からトラックへドラッグして追加することもできます |
| 分割・削除・複製 | 再生位置で「分割」（`S`）。クリップを選んで「削除」（`Delete`）・「複製」（`Ctrl+D`） |
| 速度・音量 | 0.25〜8 倍の速度変更、音量（0〜200%）、ミュート |
| トランジション | フェードイン・フェードアウト、前のクリップとのクロスフェード |
| 配置 | 全体を表示・画面を埋める・引き伸ばす、ズーム（開始と終了を変えると、ゆっくり寄る／引く動きになります）、位置、回転、左右反転。プレビュー上のドラッグでも位置を動かせます |
| 色・フィルター | 明るさ・コントラスト・彩度・色相・モノクロ・セピア・ぼかし。プリセット（モノクロ・セピア・ビビッドなど）もあります |
| テキスト（テロップ） | 「＋テキスト」（`T`）で再生位置に追加。フォント・サイズ・色・縁取り・影・背景・揃え・登場アニメーション（下から・拡大・タイプライター）を設定でき、プレビュー上でドラッグして移動できます |
| BGM・効果音 | 音声トラックに置いたクリップは、映像とは別に位置・範囲・音量・フェードを調整できます |
| 静止画保存 | 「静止画保存」で、表示中のフレームを PNG で保存 |

タイムラインは `Ctrl` + ホイールまたは「ズーム」で拡大・縮小、「全体表示」で全体が収まる倍率になります。「スナップ」がオンのときは、ほかのクリップの端や再生位置にぴったり合わせて配置されます。

### 書き出し・保存

| 操作 | 内容 |
|---|---|
| `Ctrl+E` / 「書き出し」 | 編集した動画を MP4（H.264 / AAC）または WebM（VP9・VP8 / Opus）で保存。選べる形式はブラウザによって異なります。画質は 4 段階から選べます |
| `Ctrl+S` / 「プロジェクト保存」 | 編集内容を JSON ファイルに保存（素材ファイル自体は含まれません） |
| 「プロジェクトを開く」 | 保存した JSON を開いて編集を再開。素材は「開く」で同じファイルを選ぶと、ファイル名で自動的に再リンクされます |

### 対応ブラウザ

最新の Chrome / Edge を推奨します（MP4 と WebM の両方で書き出せます）。Firefox では WebM のみで書き出せます。Safari でも動作しますが、色・フィルターが効かない場合があります。

### 制限事項

- **書き出しには、動画の長さと同じだけ時間がかかります**（実際に再生しながら録画する方式のため）。書き出し中はタブを前面に表示したままにしてください。裏に回すとコマ落ちします。
- ブラウザが再生できない形式の動画（一部の HEVC / H.265、AVI など）は読み込めません。
- 書き出した動画のフレームレートは、パソコンの処理速度によって多少揺らぐことがあります。重い場合は出力サイズを小さくしてください。
- プロジェクトファイルには素材ファイルが含まれないため、別のパソコンで開くときは素材も一緒に移してください。
- タイムライン上のクリップごとに再生用のプレーヤーを用意するため、非常に多くのクリップ（数十個以上）を並べると動作が重くなることがあります。

大切なファイルは、編集前にコピーを取ってからお使いください。
