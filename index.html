ローカルエディタ集

ブラウザだけで動くファイルエディタです。開いたファイルの読み込み・編集・保存はすべて端末の中で行われ、ファイルの中身がどこかへ送信されることはありません。

  • Excel エディタ.xlsx / .xls / .csv の編集、数式、グラフ
  • Word エディタ.docx / .doc の編集
  • PowerPoint エディタ.pptx / .ppt の編集
  • 動画エディタ動画のカット・書き出し
  • 音楽エディタ音声ファイルの編集
  • 画像エディタ画像の加工
  • HTML エディタWeb ページのレイアウトをマウスで編集

各 HTML ファイルはダウンロードしてオフラインでも使えます。
